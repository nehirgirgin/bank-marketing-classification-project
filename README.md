# Bank Marketing Term Deposit Prediction

## Project Overview
This machine learning project focuses on predicting whether a customer will subscribe to a bank term deposit based on marketing campaign data.

The project includes:
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Outlier detection and handling
- Machine learning model training
- Model evaluation and comparison

The objective is to build accurate classification models and analyze customer behavior patterns using banking marketing data.

---

## Dataset
The dataset contains customer demographic information, campaign interaction details, and financial indicators collected from a direct marketing campaign.

Target variable:
- `y` → Whether the client subscribed to a term deposit (`yes/no`)
